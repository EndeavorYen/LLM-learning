## 觀察（非事先登錄，僅供後續設計參考）
- **D2 有中等訊號**：雙腦判斷未知第 2 階段句的規律 59%，高於凍結 Qwen 最近鄰 47%、隨機漏斗 48%、字元重疊 36%；但 seed 間差異大（50%–67%）
- **B1 輸給 Qwen 零樣本**（42% vs 56%）：直接用語言模型的條件機率選句，比經過漏斗與跳躍更好
- **A1 高、B1 低**：ŝ2 常落在正確錨點，但在同一領域 3 個候選之間比較時分不出來
- **漏斗嚴重過擬合**：72 句訓練句的 s 幾乎完全貼在類別錨點上（s_pull ≈ 0）；seed 42 的（規律 0, 階段 3）與（規律 2, 階段 3）錨點完全重合（cos = 1.00），seed 1 為 0.68
- 36 題的統計量有限：B1 42% 的 95% 信賴區間約為 26%–58%
