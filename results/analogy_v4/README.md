## 診斷：屬於「沒學會」，不是「學會但無法遷移」
- **HOP 在訓練資料上就只有 61–69%**，而同樣資料上的整段前提分類器是 100%。跳躍在訓練時就沒學會依第 0 階段選分支
- **訓練 loss 與「只預測兩分支平均」的捷徑相符**：teacher-forced 跳躍 loss 0.17–0.26；若在分岔點輸出兩個分支錨點的平均，loss 約在此範圍。餘弦回歸讓模型可以不看前文就把 loss 壓低
- **資訊其實在 s 空間裡**：只用 s0 的最近錨點（S0-RULE）就有 70%，代表漏斗有保留走向資訊，是跳躍沒有用上
- **實作上的可疑點**：`law_brain` 沒有位置編碼；只訓練 400 步且與漏斗同時訓練；跳躍損失是餘弦回歸，容易學成平均
- **錨點選句器本身也偏弱**：給定正確規律時第 2 階段只有 71%（MLP 選句器 76%）

**結論：在目前的實作下，聯想跳躍沒有使用前文的能力，這是訓練失敗，尚不能歸因於理論。** 下一步應先讓跳躍在訓練資料上學會（已見領域 BR 接近 100%），才能判斷它能否遷移。
