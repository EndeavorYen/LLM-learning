## 這次能確定的事
1. **s 漏斗學到了可遷移的「規律」表徵。** 在全新領域、無關鍵字線索、經 7B 驗證可答的題目上，D2 達到 89%，遠高於凍結 Qwen 特徵（56–58%）、隨機漏斗（49%）與打亂標籤（39%）
2. **`law_brain` 跳躍沒有貢獻。** A1 只比「直接把 s1 分類」高 3 個百分點，雙腦的優勢幾乎全部來自漏斗的分類能力
3. **還缺一個關鍵對照組：一般的監督式分類器。** 雙腦使用了 216 句帶標籤的訓練資料，而語言模型基線沒有標籤。若一個普通的線性分類器（沒有 d/s 分離、沒有正交約束）用同樣的標籤也能達到 89%，那麼優勢來自「有標籤的監督學習」，而不是雙腦結構。這個對照組不在本次登錄的規格中，應作為下一輪的第一優先
